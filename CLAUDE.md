# EcoDome wiki

This repository is an LLM-maintained knowledge wiki. Before ingesting a source, answering from the wiki, or linting it, read [AGENTS.md](AGENTS.md) and follow it.

The OKF v0.2 bundle is `wiki/`. Raw sources in `raw/` are immutable. Concept pages stay at project-level facts. Run `python scripts/validate_okf.py` before finishing a wiki change.
