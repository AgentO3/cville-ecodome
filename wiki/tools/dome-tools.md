# What the notes say

The [community notes](/sources/community-context.md) name Dome Tools, by Prefrontal Cortex, as a Unity-based tool for real-time dome projection: <https://prefrontalcortex.de/en/projects/dome-tools/>. They record an idea that was floated, not a decision: a WebXR toolkit that pulls in Dome Tools for a hackathon, and virtual multiplayer watch parties.[^community-context]

The [AI Explorers deck](/pilot/april-2027.md) proposes a different pre-festival hackathon and does not mention Dome Tools. The [EARS specification](/simulator/acceptance-and-delivery.md) excludes multiplayer synchronization from the simulator's first release. The [immersive content](/dome/immersive-content.md) page is where projection and media requirements live. Whether any of these ideas should converge is an [open question](/questions/open-questions.md).
